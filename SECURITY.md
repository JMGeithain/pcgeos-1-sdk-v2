# Reporting problems

For malformed-file handling, unsafe archive extraction or command construction issues, open a minimal issue without uploading a proprietary runtime, personal document or secret. Include the SDK version, host, command and a small original reproducer when possible.

The Perl inspector does not execute `.GEO` or `KERNEL.EXE` input. Building intentionally executes the configured external compiler/linker. Use known source repositories and pinned tool downloads. Runtime tests belong in an isolated copy or emulator.

Deutsch: Bitte minimale Fehlerbeispiele ohne private oder nicht zur Weitergabe freigegebene Dateien melden. Der Prüfer führt eingelesene Geoden nicht aus; ein Build startet dagegen bewusst die konfigurierten Compiler-/Linker-Werkzeuge. Native Tests nur mit einer getrennten Testinstallation durchführen.
